Quick Reference Cheat Sheet

Commands, shortcuts, and links you'll use often during your TC internship.

💡
PRO TIP
Bookmark this page. Stop EC2 instances when not in use to save costs. Always login to Tenable through the MSSP portal.

☁️ AWS CLI

aws ec2 describe-instances

List all EC2 instances

aws ec2 stop-instances --instance-ids i-xxxx

Stop an instance to save costs

aws ec2 start-instances --instance-ids i-xxxx

Start a stopped instance

aws s3 ls

List S3 buckets

aws sts get-caller-identity

Verify which AWS account/role you are using

🔑 SSH / EC2 Connect

ssh -i key.pem ec2-user@<public-ip>

Connect to Amazon Linux instance

ssh -i key.pem ubuntu@<public-ip>

Connect to Ubuntu instance

chmod 400 key.pem

Fix key permissions (required before SSH)

scp -i key.pem file.txt ec2-user@ip:~/

Copy file to remote EC2

📊 Splunk Search

index=main | head 20

Show first 20 events

index=main host=apache-1

Filter by host

index=* sourcetype=linux_secure failed

Find failed Linux logins

| stats count by host

Count events grouped by host

earliest=-24h@h

Filter to last 24 hours

🦅 CrowdStrike Falcon

sudo /opt/CrowdStrike/falconctl -g --cid

Check installed Customer ID

sudo /opt/CrowdStrike/falconctl -g --aid

Check sensor Agent ID

sudo systemctl status falcon-sensor

Check sensor service status

sudo systemctl restart falcon-sensor

Restart Falcon sensor

🛡️ Tenable Nessus Agent

sudo /opt/nessus_agent/sbin/nessuscli agent status

Check agent linked + last connect

sudo systemctl status nessusagent

Check agent service

sudo systemctl restart nessusagent

Restart Nessus agent

sudo /opt/nessus_agent/sbin/nessuscli agent unlink

Unlink an agent

🐧 Linux Basics

sudo dnf update -y

Update packages (Amazon Linux 2023)

sudo systemctl status <service>

Check service status

journalctl -u <service> -n 100

View last 100 log lines for a service

top

View running processes

df -h

Check disk space
